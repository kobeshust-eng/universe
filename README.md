## Открыть интерактивный атлас

1. [Скачайте этот архив](https://github.com/kobeshust-eng/universe/archive/refs/heads/main.zip) и распакуйте.
2. Откройте `мир менделеевых/атлас/dist/index.html` в браузере.

Установка и интернет не нужны. В атласе есть граф, карточки объектов, фотографии, незаполненные места для новых идей и игра «Угадай, кто я — летим на КОТ».

[Подробный сценарий для созвона](мир%20менделеевых/игры/2026-10-18-экспедиция-на-кот.md)

Данные сохраняются в папке **мир менделеевых**. Исходные изображения не изменены. У BMW управление силой мысли и мановением. Встречи записываются отдельными файлами и коммитами; автоматическая синхронизация чата не включена.
