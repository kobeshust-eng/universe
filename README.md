## Открыть интерактивный атлас

Откройте [mendiplay.ru](https://mendiplay.ru/). В атласе есть карта связей, карточки объектов, оригинальные семейные рисунки рядом с дорисовками и пустые места для будущих находок. В разделе игры 1–4 участника могут вместе отправиться на пять планет с одного экрана.

Без сети: [скачайте этот архив](https://github.com/kobeshust-eng/universe/archive/refs/heads/main.zip), распакуйте и откройте `мир менделеевых/атлас/dist/index.html` в браузере.

Комнаты для игры с разных устройств реализованы в Node-сервере, но пока не подключены к публичному хостингу. [Как запустить сервер](мир%20менделеевых/атлас/server/README.md).

[Подробный сценарий для созвона](мир%20менделеевых/игры/2026-10-18-экспедиция-на-кот.md)

Данные сохраняются в папке **мир менделеевых**. Исходные изображения не изменены. У BMW управление силой мысли и мановением. Встречи записываются отдельными файлами и коммитами; автоматическая синхронизация чата не включена.
