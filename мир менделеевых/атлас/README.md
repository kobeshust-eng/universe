# Интерактивный атлас

Обычные HTML, CSS и JavaScript без сборочных зависимостей. Публичная версия: [mendiplay.ru](https://mendiplay.ru/). Для локального просмотра откройте `dist/index.html` или запустите `python3 -m http.server 8765 --directory dist` из этой папки.

Первая версия совместной игры находится в `dist/game/`; режим на одном экране для 1–4 игроков работает и на публичном сайте. Для комнаты с разных устройств запустите `node server/server.js` (Node.js 20+), затем откройте `http://127.0.0.1:8766/game/`. Этот сервер пока не подключён к публичному REG.RU Host-0. Подробности и проверки — в [инструкции сервера](server/README.md).

Каталог и вопросы приходят из `../каталог.json`. После правок запустите `python3 собрать.py`: скрипт обновит `dist/data.js` и медиа. В `dist/` хранятся готовые файлы для размещения.

Заметки из игры — локальный черновик браузера. Для переноса в архив используйте «Скачать бортовой журнал». На GitHub они автоматически не отправляются.
