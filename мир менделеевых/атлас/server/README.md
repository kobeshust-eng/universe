# MendiPlay — игра и сервер комнат

Рабочая первая версия от 19 октября 2026. Один экипаж из 1–4 игроков, общий маршрут и пять мини-игр. Для фронтенда и сервера используется один движок правил `dist/game/engine.js`; онлайн-состояние меняет только сервер.

## Запуск

Нужен Node.js 20 или новее. Внешние npm-пакеты не нужны.

```sh
node server/server.js
```

Команда выполняется из папки `атлас`. По умолчанию адрес — `http://127.0.0.1:8766/`, игра — `/game/`. Сервер раздаёт весь `dist`, включая семейный атлас. `HOST` и `PORT` задаются переменными окружения. Для доступа по домашней сети можно запускать с `HOST=0.0.0.0`; для публикации предпочтителен локальный адрес за HTTPS-прокси.

Обычный статический хостинг поддерживает игру на одном экране. Для комнат с разных устройств обязательно запускать этот сервер, а запросы `/api/` направлять на него.

## Что можно играть

| Планета | Задание | Механика |
| --- | --- | --- |
| Земля | Звёздная почта | Одновременное перемещение, совместный сбор предметов |
| Альфа | 14 шаров поля | Забрать один энергомодуль и доставить на свободную точку |
| Марс | Эхо | Запоминание и повторение удлиняющейся последовательности |
| Юпитер | Оркестр облаков | Попадание кнопкой в широкое ритмическое окно |
| Art Planet | Мозаика для телескопа | Раскрашивание по образцу, общий прогресс |

Механики и имена трёх пришельцев — игровые предложения, не новые обязательные факты мира. У всех занятий нет штрафов и проигрыша. Число посылок и музыкальных попаданий зависит от размера команды. Все 14 шаров Альфы сохраняются при любом числе игроков.

Командир выбирает планету. Каждый отмечает готовность. Командир запускает общий перелёт. За завершённое задание команда получает три звезды. Корабль можно вызвать в любой момент.

## Управление

- 1-й игрок: WASD; 2-й: стрелки; 3-й: IJKL; 4-й: TFGH.
- Музыкальный звук: E / Enter / O / Y соответственно.
- Экранные стрелки поддерживают несколько одновременных касаний.
- В мозаике и памяти на общем экране можно выбрать активного героя кнопкой. С разных устройств каждый действует своим героем.
- Условные аватары семьи — временные цветные фигурки, не портретное сходство. Список содержит 14 членов семьи и 3 придуманных пришельцев.

## Онлайн-комнаты

Создатель получает шестизначный код, которым делится с семьёй. До четырёх участников. Присоединение разрешено в корабле до полёта. Сервер передаёт общее состояние через Server-Sent Events 10 раз/с; симуляция движется 20 раз/с. HTTP-действия авторизованы случайным токеном участника. Токены не входят в общее состояние и передаются заголовком Authorization. Повороты, движения и победу проверяет общий движок на сервере.

При обрыве потока клиент повторяет подключение. Потерянное управление сбрасывается за секунду. Участник без подключения удаляется через 90 секунд; если это командир, роль получает следующий. Комнаты живут в памяти до 6 часов без действий. Перезапуск сервера удаляет все комнаты. Перезагрузка страницы создаёт новый сеанс: восстановления по аккаунту пока нет. Голосового чата, сохранений и геймпадов нет.

## Проверки

```sh
node server/test.js
node server/integration-test.js
```

Второй тест требует работающего локального сервера на 8766; другой адрес можно задать через `TEST_URL`.

Проверено: все пять заданий завершаются при составе 1, 2, 3 и 4 человека; перелёт требует готовности; пятый игрок отклоняется; чужой токен и выбор маршрута не командиром отклоняются; четыре онлайн-участника получают один мир и вместе завершают мозаику. В Chrome пройдены локальная партия с четырьмя игроками, мозаика, перелёт на Альфу, движение клавиатурой; на ширине 390 px нет горизонтального переполнения и ошибок JavaScript. Отдельно проверены две независимые вкладки Chrome: вход по коду, общая готовность, синхронный перелёт, поочерёдная работа над мозаикой и общая победа.

## Размещение на VPS

Достаточно одной копии сервера. За reverse proxy нужно передавать исходный Host, выключить буферизацию SSE и установить достаточно длинный таймаут. Пример для существующего HTTPS server-блока nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:8766;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_read_timeout 3600s;
}
```

Сервер не выпускает TLS-сертификаты и не меняет DNS. HTTPS на домене настраивается отдельно на хостинге. Для systemd используйте непривилегированного пользователя, рабочую папку `атлас`, `ExecStart=/usr/bin/node server/server.js`, `Restart=on-failure`, `Environment=HOST=127.0.0.1` и `Environment=PORT=8766`. Масштабирование на несколько процессов потребует общего хранилища комнат или привязки комнаты к одному процессу; сейчас достаточно одной копии.

Для хостинга с контейнерами подготовлен `server/Dockerfile`. Из папки `атлас`: `docker build -f server/Dockerfile -t mendiplay .`, затем публикация порта 8080 через HTTPS-прокси. Сборка контейнера в этой среде не запускалась; Node-сервер проверен напрямую.
