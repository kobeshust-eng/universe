## Что лежит в архиве

- `объекты/` — карточки с фактами, авторами, фотографиями и связями.
- `медиа/` — неизменённые копии шести предоставленных PNG, три художественные дорисовки и актуальная карта.
- `встречи/` — журнал решений по реальным датам.
- `игры/` — идеи будущих встреч; они ещё не стали фактами мира.
- `источники/` — записи рассказов и реестр файлов с контрольными суммами.
- `каталог.json` — структурированные данные для будущего альбома или приложения.

В оформлении карты встречаются декоративные планеты и детали. Они не становятся отдельными объектами мира без решения семьи.
