# Где хранить мир

Рекомендация для этой семьи: GitHub — основная история и исходники; интерактивный атлас — удобный просмотр; отдельная семейная медиапапка пригодится, когда появятся длинные видео и аудиозаписи.

## Obsidian: открыть уже готовую папку

Удобен как личная энциклопедия на обычных файлах. Наши Markdown-карточки можно открыть в нём, а изображения, аудио, видео и PDF встраивать в записи. Это позволяет работать с тем же архивом, а не вручную переносить факты в ещё одну базу. Синхронизацию между устройствами нужно настроить отдельно.

Источник: [поддерживаемые форматы Obsidian](https://obsidian.md/help/file-formats).

## Notion: карточки как музейная витрина

Подходит, если удобнее добавлять объекты через визуальную базу с полями «автор», «тип», «планета», «статус» и обложкой. Представление Gallery показывает карточки с изображениями. Потребуется решить, где главный текст, чтобы Notion и GitHub не начали расходиться. Ограничения размера вложений зависят от плана — перед переездом стоит проверить их.

Источники: [галереи Notion](https://www.notion.com/en-gb/help/guides/gallery-view-databases), [файлы и медиа](https://www.notion.com/help/images-files-and-media).

## Физические вещи

Для поделок нужна настоящая коробка или полка. На карточке можно указать место хранения и положить рядом бумажку с ID. Цифровая запись содержит фотографии с разных сторон, автора и историю. Для рисунков сохраняем исходное фото, для голосового рассказа — аудио и короткую расшифровку, для 3D-модели — файл и картинку-превью.

## Как не запутаться

Одно имя объекта и стабильный ID связывают рисунок, поделку, историю и запись голоса. Сегодня установленный факт меняется в каталоге и карточке; идея остаётся вопросом; после встречи появляется отдельная запись с датой. GitHub сам не забирает новые сообщения из чата — архив обновляется при работе в этой задаче.
