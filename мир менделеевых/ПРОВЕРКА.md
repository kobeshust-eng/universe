# Проверка перед созвоном

Проверено 18 октября 2026 года.

- 17 карточек, 6 исходных фотографий, исправленная карта и 32 творческих задания присутствуют.
- Все локальные ссылки в Markdown ведут к существующим файлам.
- SHA-256 исходных фотографий совпадает с реестром.
- Размеры и Git SHA всех семи изображений на GitHub совпадают с локальными файлами; те же изображения проверены в папке атласа.
- JavaScript проходит проверку синтаксиса.
- В браузере проверены граф и карточка BMW, фотографии и увеличение, поиск КОТ, фильтр заданий и переключатель будущих открытий.
- В браузере проверены выбор игровой роли, показ ответа и сохранение черновика журнала после перезагрузки.
- Ошибок JavaScript в проверенном сценарии не обнаружено.

Ограничения проверки: встроенный браузер не разрешает открывать file:// и не подтвердил событие скачивания журнала. Атлас проверен через локальный HTTP-сервер; его файлы не используют сетевые запросы для каталога и фотографий. Кнопку скачивания журнала в обычном браузере отдельно не проверяли. Текст журнала всегда доступен для ручного копирования.

Публикация в Sites не выполнена: автоматическая проверка разрешений отклонила отправку семейных материалов в другой сервис. Полный архив и исходники атласа сохранены в разрешённом репозитории GitHub. На компьютере готова ZIP-копия атласа.
